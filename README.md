## 宝さがし（開発版）

草原の西側で遊べる、小さな冒険です。

1. はじまりは、祠への小道のそばにいるふくろうのポポ。話しかけると宝さがしが始まります。
2. 手がかりは、ねこ・下を向いて咲く花・小さな泉の3つ。ヒントをたよりに、この順で見つけていく。
3. 水の流れの先には宝箱。開けると、光るランタンと世界のひみつのかけらが手に入ります。
4. 最後は暗いほらあな。ランタンで照らすと、新しい手がかりが見えてくる。

ヒントは聞き直すたびに、少しずつくわしくなります。聞いたヒントと持ち物は、左上の「📖 冒険メモ」で読み返せます。手がかりの場所と進む順番は固定のデータで決めていて、AI の返事では変わりません。

## 遊んだ記録の保存

| 記録 | 残る場所 | 開きなおしたとき | 「デモを最初から」 |
|---|---|---|---|
| 宝さがしの進み具合・もちもの | この端末のブラウザ（localStorage） | 続きから遊べる | 消える |
| 写真 | 開いているページの中だけ（サーバーへ送らない） | 消える | 消える |
| 写真から始まるクエスト・第2クエスト・道くさ・見つけたもの | 開いているページの中だけ | 最初から | 消える |
| AI の回数を数えるための匿名の番号 | 開いているタブの中だけ（sessionStorage） | タブを閉じると消える | 消えない（タブを閉じるまで同じ番号） |

- 宝さがしの記録は、ブラウザごと・端末ごとに別々です。ほかの端末やブラウザには引きつがれません。
- 開発版（ファイル名に `preview` が入るページ）は、公開版とは別の名前で保存します。どちらで遊んでも、もう一方の記録は上書きされません。
- 名前・年齢・メールアドレスなどは集めません。
