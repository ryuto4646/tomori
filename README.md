# TOMORI（開発用リポジトリ）

写真と自分のことばで探究する、ブラウザで遊べる 3D の冒険ゲームです。

- 公開中の作品（宝さがし入り）：https://ryuto4646.github.io/tomori/demo-world.html
- 開発版（次の調整を実機で確かめる版）：https://ryuto4646.github.io/tomori/demo-world-preview.html
- 紹介ページ：https://ryuto4646.github.io/tomori-lp/
- コンテストに提出した版は、タグ `contest-submission-2026-10-11` に残しています。

## 宝さがし

草原の西側で遊べる、小さな冒険です。

1. はじまりは、祠への小道のそばにいるふくろうのポポ。話しかけると宝さがしが始まります。
2. 手がかりは、ねこ・下を向いて咲く花・小さな泉の3つ。ヒントをたよりに、この順で見つけていく。
3. 水の流れの先には宝箱。開けると、光るランタンと世界のひみつのかけらが手に入ります。
4. 最後は暗いほらあな。ランタンで照らすと、新しい手がかりが見えてくる。

写真から始まる問いは、パネルの「あとで・冒険にもどる」でいったん閉じられます。閉じた場所の近くで「続ける」を押すと、同じ問いの続きから始まります。近づいただけでは開きません。

AI の返事を待っているあいだでも閉じられます。閉じているあいだに返事が届いても、パネルは開かず、問いも進みません。「続ける」を押すと、その返事を使って続きを出します。同じ内容を送り直すことはありません。返事が届かなかったときや時間切れのときは、端末の中で用意したことばで続けます。

ヒントは聞き直すたびに、少しずつくわしくなります。聞いたヒントと持ち物は、左上の「📖 冒険メモ」で読み返せます。手がかりの場所と進む順番は固定のデータで決めていて、AI の返事では変わりません。

## 巨木への冒険（開発版）

宝さがしの続きです。ほらあなのかべの絵を見つけたところから始まります。

1. かべの絵と同じもようの、古い石の門をさがす。場所は、ポポとミナがヒントをくれます。
2. 門をしらべると、世界のひみつのかけらが光って、巨木への道がひらく。かけらは減らず、もちものに残ります。
3. 道を歩いていくと、巨木の根もとで大きな生きもの「オオネ」がねむっている。しらべると、目をさまします。
4. オオネに、冒険で気になったことを伝える。「何が気になった？」「どんなところが気になった？」の2つの問いに、選んで答えても、短いことばで答えてもかまいません。
5. お礼に、ひかりのつるのタネを1つもらう。巨木の向こうで道が切れている場所に植えると、光るつるが育って橋になる。
6. 橋をわたると、向こう岸に着く。遠くの空に、次の冒険の目印が見えます。

オオネとの話も、「あとで・冒険にもどる」で閉じられます。返事を待っているあいだでも閉じられ、そのあいだに返事が届いてもパネルは開きません。タネもまだ受け取りません。オオネの前で「続ける」を押すと、同じところから続きます。

オオネが返す受けとめのひとことには、写真のクエストと同じ AI（Worker）を使うことがあります。使うのは、子どもが自分のことばを書いたときだけ。選んで答えたときは通信せず、用意したことばを返します。AI が決めるのはこのひとことだけで、道がひらく条件・タネ・もちものは固定のデータで決まる。通信できないときや時間切れのときも、用意したことばで続きます。つらさや危険を示すことばは送らず、写真のクエストと同じ案内を出す決まりです。

オオネの姿と、道ぞいの音・光・草花は、どちらもまだ仮のものです。今は基本の形だけで作っています。

## 遊んだ記録の保存

| 記録 | 残る場所 | 開きなおしたとき | 「デモを最初から」 |
|---|---|---|---|
| 宝さがしの進み具合・もちもの | この端末のブラウザ（localStorage） | 続きから遊べる | 消える |
| 巨木への冒険の進み具合（道がひらいた・オオネと話した・タネ・橋・向こう岸） | 宝さがしと同じ記録の中（localStorage） | 続きから遊べる | 消える |
| オオネに書いたことば・選んだこと | 開いているページの中だけ（端末には残さない） | 最初から（もう一度、問いから話す） | 消える |
| 写真 | 開いているページの中だけ（サーバーへ送らない） | 消える | 消える |
| 写真から始まるクエスト・第2クエスト・道くさ・見つけたもの | 開いているページの中だけ | 最初から | 消える |
| 「あとで・冒険にもどる」で閉じた問いの続き（選んだ写真・書いたことば） | 開いているページの中だけ | 最初から | 消える |
| AI の回数を数えるための匿名の番号 | 開いているタブの中だけ（sessionStorage） | タブを閉じると消える | 消えない（タブを閉じるまで同じ番号） |

- 宝さがしの記録は、ブラウザごと・端末ごとに別々です。ほかの端末やブラウザには引きつがれません。
- 公開版は `tomori-treasure-v1`、開発版（ファイル名に `preview` が入るページ）は `tomori-treasure-v1-preview` という名前で保存します。どちらで遊んでも、もう一方の記録は上書きされません。
- 巨木への冒険の記録は、宝さがしと同じ名前の記録に項目を足したもの。前の記録（この項目がないもの）もそのまま読み込めるので、宝さがしを終えた人は、その続きから始められます。
- オオネに書いたことばを AI（Worker）へ送るのは、「つたえる」を押したときの1回だけ。写真・名前は送りません。
- 名前・年齢・メールアドレスなどは集めません。
