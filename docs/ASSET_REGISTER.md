# 素材の記録（ASSET_REGISTER）

ゲームに入れる素材の出どころ・作り方・利用条件・大きさ・採用状態の一覧。
新しい素材は、入れる前にこの表へ書き、利用条件と容量を実際に確かめてから採用します。

- 家と屋台は、ひとつの形にまとめて1回で描きます。透かすときは、家ごとの番号で点を抜きます。

## Meshy（予定）

制作者の指示（2026-11-13）は、家1種類と屋台1種類を先に作り、採用されたら噴水を追加する、というものです。

- Claude から Meshy を操作する手段はない。制作者の素材を待たずに、上の仮素材で進めています。
- 素材が届いたときの置き場所：元のデータは `assets/source/`（公開しない場所）、軽くした版は別のファイル。
- 届いたら、下の表の項目をすべてうめます。プロンプトの全文は、表の下に残します。
- めやす：家1万三角形以下、屋台・噴水5千以下、テクスチャは原則1024以下。iPhone での見た目と重さで決めます。
- 追加のクレジット購入・契約変更はしません。
