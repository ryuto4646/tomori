# 素材要件一覧

TV収録デモ用3D探索シーンに必要な素材を整理する。
★ = 必須　☆ = あると良い　△ = 任意（なければ手続き生成で代替可能）

---

## 1. キャラクター

### ヒロリ（メインキャラクター）

| 項目 | 要件 |
|---|---|
| **ファイル名** | `assets/characters/hiroli.glb` |
| **形式** | GLB（glTF 2.0 バイナリ） |
| **推奨ポリゴン数** | 3000 triangle 以下（スマートフォン向け） |
| **推奨テクスチャ** | 1024×1024 px、PNG または JPEG |
| **スケール** | Three.js シーン内で高さ 1.6〜2.0 ユニット相当 |
| **ピボット** | 足元中央（0, 0, 0） |
| **必須度** | ★ |

受領前は CapsuleGeometry（高さ 1.6、半径 0.35）＋マテリアルで代替動作する。
GLB を `/assets/characters/hiroli.glb` に配置するだけで自動切り替わる。

#### 必要なアニメーションクリップ（GLB 内に埋め込み）

| クリップ名 | 説明 | 必須度 |
|---|---|---|
| `idle` | 立ち止まっている状態。呼吸・体の揺れなど | ★ |
| `walk` | 歩行ループ（前進） | ★ |
| `discover` | 探究地点を見つけたとき（驚き・喜び） | ☆ |
| `celebrate` | ミッション達成時 | ☆ |
| `think` | AI が質問するとき（考える仕草） | △ |

クリップが 1 つしかなくても動作する（`idle` だけで進行可能）。
クリップ名が上記と異なる場合は `CHAR_ANIM_MAP` 定数に対応表を記入する（コード内にコメントあり）。

## 7. ポリゴン数・テクスチャ総量の目安

### スマートフォン向け目安

| 項目 | 目安 |
|---|---|
| シーン全体のポリゴン数 | 20,000 triangle 以下 |
| テクスチャ総メモリ | 8MB 以下（VRAM 節約） |
| GLB 総ファイルサイズ | 5MB 以下（初回ロード速度） |
| 目標フレームレート | 30fps 以上（60fps 推奨） |

### ローポリ優先の考え方

既存アプリは平面的なイラスト＋グロー演出の世界観。
3D の目標スタイルは「ファンタジーなローポリ」。
ポリゴンが少なくても、発光・パーティクル・色の対比で十分に魅力的になる。

## 8. 代替手段まとめ（素材ゼロで動作するデモの構成）

すべての素材が未受領の場合でも、以下の手続き生成で検証が進む。

| 素材 | 代替 |
|---|---|
| ヒロリ | CapsuleGeometry（高さ 1.6、半径 0.35）+ MeshToonMaterial |
| 木 | CylinderGeometry（幹）+ ConeGeometry（葉）|
| 花 | SphereGeometry（小、3色バリエーション） |
| 岩 | DodecahedronGeometry |
| ミッション地点 | TorusGeometry + PointLight + Y軸pulse |
| 地面 | PlaneGeometry（緑単色） |
| 空 | scene.background = Color（水色） |
| 音 | なし（サイレント） |

手続き生成コードはすべて `demo-world.html` 内に `createPlaceholder*()` 関数として実装済み。
GLB を所定パスに置くと自動的に GLB が優先される。
