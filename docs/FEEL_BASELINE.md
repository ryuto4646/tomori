# 歩き方と発見の演出の基準（2026-10-16 採用）

宝さがしを公開するとき（TOMORI-TREASURE-RELEASE-01）に、iPhone の実機で確かめて採用した値です。
今後、歩き方や演出を変えるときは、この値を出発点にします。
変えたときは、変える前と後を同じ距離・同じ画角の動画でくらべ、このファイルも書きかえてください。

数値はすべて `demo-world.html` の中にあります。かっこの中は、探すときの名前です。

## 歩き方（ヒロリ）

ねらいは「たったった」と一歩ずつの間が感じられる歩き方です。「タタタタ」と小走りに見える速さには戻しません。

| 項目 | 採用した値 | 前の値 | 場所 |
|---|---|---|---|
| 歩く速さ（m/秒） | 3.3 | 4.0 | `SPEED` |
| 歩幅の周期 | 1.5 | 0.9 | `STRIDE_RIG` |
| 足の前後の振れ | 0.1 | 0.075 | `RIG_REACH` |
| 足の上がる高さ | 0.05 | 0.028 | `RIG_LIFT` |
| 体の上下 | 0.035 | なし | `STEP_BOB` |
| 前かがみ | 0.07 | なし | `STEP_LEAN` |
| 一歩の中の速さの強弱 | 0.22 | なし | `STEP_PACE` |

- 結果は、1秒に約4.4歩です。前の値では約9歩でした。
- 速さ・歩幅・上下の揺れは、3つ一緒に調整します。速さだけを変えると、足がすべって見えます。
- 「動きを減らす」設定の端末では、一歩の中の速さの強弱を止めます（`pace()` が 1 を返す）。

## 発見の演出

どの演出も、3D の世界で見せてから説明のパネルを出します。
ごほうびは演出を始める前に決めて保存するので、連打しても、途中で閉じても、読み込みなおしても、二重にはもらえません。

| 場面 | 長さ | 流れ | 色 |
|---|---|---|---|
| 宝箱 | 2.4 秒 | 少しゆれる → ふたが開く → 光がもれる → ランタンとかけらが出て浮かぶ → ヒロリのところへ（手に入れた表示） | 金色の光の筋と粒 |
| ランタン | 0〜2.0 秒 | 灯りがともる → ほらあなの入口と壁が照らされる → 壁の絵が浮かぶ | だいだい色 |
| ひみつ | 2.0〜3.6 秒 | 絵の中の大きな木が光る → 光の粒が遠くの大きな木のほうへ → 遠くの木の光がふくらむ | 青白い色 |

- ランタンとひみつは、続けて起きる1つの演出（`EV_DUR.cave` = 3.6 秒）です。
- 「動きを減らす」設定の端末では、同じ順番を 0.6 秒で見せ、ゆれ・粒・ちらつきを止めます。
- 効果音はその場で作る短い音です。音のファイルは使いません。最初に画面へふれたあとから鳴ります。
- 強い点滅は使いません。長く待たせることもしません。
- 演出に使う物の描き方と絵は、読み込みのときに用意します（`warmUp`）。はじめての演出で、1コマが止まらないようにするためです。

## 重さの目安

採用した版をヘッドレス Edge（GPU：Intel Iris Xe・D3D11）で測った値です。
演出を変えたら同じ方法で測り、ここより大きく悪くならないことを確かめます。

| 区間 | スマホ幅（390×844、拡大率2倍） | PC（1280×800） |
|---|---|---|
| 西の草原（演出なし） | 60fps・JS p95 1.6ms | 60fps・JS p95 2.0ms |
| 宝箱 | 60fps・JS p95 1.4ms・最大 3.3ms | 60fps・JS p95 1.9ms・最大 5.7ms |
| ランタン | 60fps・JS p95 1.2ms | 60fps・JS p95 1.9ms |
| ひみつ | 60fps・JS p95 1.3ms | 60fps・JS p95 2.2ms |

JS は、描画ループの中の1コマの処理時間です。p95 は、95% のコマがこの時間以下だったという意味です。
