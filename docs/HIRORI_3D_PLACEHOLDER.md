# 仮ヒロリ（3Dプレースホルダー）

`demo-world.html` で歩き回るヒロリの**仮モデル**。
正式なGLBが届くまでの差し替え用で、Three.js の基本形状を組み合わせて作っている。
**正式なキャラクターデザインではない。** 形・色・比率は、正式素材で置き換わる前提。

---

## デザインの構成

中央キャラクターとして決まっている方向を、簡単な形で表した。

| 部分 | 形 | 色 |
|---|---|---|
| 体 | 細めのカプセル。すらっとした小さな二足歩行 | コーラルピンク `#e9786e` |
| 胸・おなか | 平たい楕円 | 朝のクリーム色 `#fff0d4` |
| 頭 | 丸く柔らかい球。鼻先（マズル）は付けない | コーラルピンク |
| 目 | 小さな縦長の楕円 | こげ茶 `#2b1d18` |
| 口 | ごく小さな横長の楕円 | くすんだ赤 `#9a5550` |
| 耳 | 先の丸い、ひれのような形を横へ開く | 外側コーラル、内側に淡い水色 `#a9dbe6` |
| 頭の後ろ | 花びら・ひれ3枚を扇状に | 外側コーラル、内側に淡い水色 |
| 尻尾 | 腰の後ろから伸びる、大きく平たいひれ | コーラル、内側に淡い水色 |
| 手 | 小さな球 | クリーム色 |
| 足元の影 | 半透明の円 | 深い緑 |

質感は `MeshStandardMaterial`（roughness 0.82、metalness 0）で、クレイやフェルトのような半つやにしている。
半透明にはしていない（影の円だけ半透明）。爪・牙・角は付けていない。
鼻先を付けると、キツネやネコのように特定の動物に見えたため、付けていない。

## 部位の構造

`createHiroriPlaceholder()` が `THREE.Group` を返す。足元が原点（y = 0）、正面が +z。

```
root（Group）……… 位置・向き・到着時の跳ね
├─ shadow ……………… 足元の影（跳ねても地面に残す）
├─ leftLeg / rightLeg … 腰を支点に前後へ振る
└─ body（Group）…… 呼吸・歩行の上下
   ├─ 胴・おなか
   ├─ leftArm / rightArm … 肩を支点に振る・上げる
   ├─ tail ……………… 腰の後ろを支点に揺れる
   └─ head（Group）… 首を支点に少し動く
      ├─ 頭・耳
      ├─ leftEye / rightEye … まばたき（縦につぶす）
      ├─ mouth
      └─ headPetals …… 頭の後ろの花びら・ひれ（少し遅れて揺れる）
```

動かす部位は `root.userData.parts` にまとめてある。アニメーションでは、ここを直接使い、毎フレーム検索しない。

## 動き

`updateHiroriMotion(root, dt, t, moving)` が毎フレーム呼ばれる（`animate()` の `!mixer` 分岐）。

| 状態 | 動き |
|---|---|
| idle（止まっている） | 体がごく小さく上下（呼吸）。頭がわずかに周りを見る。尻尾がゆっくり揺れ、花びらが少し遅れて揺れる。2.5〜5.5秒ごとにまばたき |
| walk（歩いている） | 脚が交互に前後。腕は脚と反対へ小さく振る。1歩ごとに体が小さく上下。尻尾と花びらは少し遅れて揺れる |
| arrival（光るポイントに着いた） | 0.9秒で1回だけ。小さく跳ね、両腕を少し上げ、花びらと尻尾がふわっと広がって、元に戻る |

- 歩きと止まりの切り替えは、0.3秒ほどかけてなめらかにつなぐ（急に固まらない）。
- 歩く周期は移動速度（`SPEED = 4.0`）に合わせ、1周期（左右1歩ずつ）で1.6進む。地面を滑って見えないようにするため。
- 向きは進む方向へ、最短回りで少しずつ合わせる（`turnToward`）。瞬間的に向きを変えない。
- 到着モーションは `triggerMission()` で始まる。ミッションパネルの表示は待たせない。リセット（`resetHiroriMotion()`）後は、もう一度出せる。
- 移動速度・到着判定・カメラ追従・タップ判定は変えていない。タップ判定は地面（`ground`）だけを対象にしているので、ヒロリの体はタップのじゃまをしない。

## prefers-reduced-motion

OS やブラウザで「視差効果を減らす」が有効な場合：

- 体の上下動（呼吸・歩行）を止める
- 到着時の跳ねを止め、腕の上げ方も小さくする
- 尻尾・花びら・頭の揺れを弱くする（約4割）
- タップ移動と脚の動きはそのまま使える

---

## モバイル性能への配慮

- 形（Geometry）は4種類だけを作り、全部位で使い回す。素材（Material）も6種類を共有する
- 球は18×14分割、小さな部位は10×8分割にとどめている
- 形・素材・オブジェクトは最初に1回だけ作り、毎フレーム作らない（テストで確認）
- 影は `shadowMap` を使わず、円を1枚置くだけ

---

## 正式GLBへ交換するときの接続点

1. `demo-world.html` の `character = createHiroriPlaceholder();` を、`GLTFLoader` で読み込む処理に戻す。
   読み込んだ `gltf.scene` を `character` に入れ、`mixer = new THREE.AnimationMixer(character)` を作る。
2. アニメーションのクリップ名を `ANIM_MAP`（idle・walk・discover・celebrate）に合わせる。
   既存の `playAnim()` がこの名前で切り替える。
3. `mixer` があると、`animate()` は仮モデルの `updateHiroriMotion()` を呼ばなくなる。
   `triggerMission()` の `startHiroriArrival()` も `!mixer` のときだけ動く。
4. 向きの補間（`turnToward`）とタップ移動・カメラ追従は、そのまま使える。
5. 足元の原点を y = 0、正面を +z にそろえる。身長は仮モデルと同じ約2.0（頭の上のラベルは足元から2.6の位置）。

---

## 正式素材で必要なもの

- ヒロリの GLB（1体・軽量。モバイルで動く大きさ）
- idle アニメーション
- walk アニメーション（移動速度 4.0 に合う歩幅）
- joy または discovery アニメーション（到着時）
- 正面・横・背面の確認画像
- 色指定（コーラルピンク・クリーム・淡い水色など、正式な値）
- 基準の身長と、足元の原点の位置
- ライセンスと制作者の情報
