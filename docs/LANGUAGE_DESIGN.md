# ことばの体験の設計（TOMORI-NEXT-LANGUAGE-AND-WORLD-01）

2026-10-20 に記録した、今後のクエスト設計の中心です。

## 中心の原則

**もっと冒険したいから、言葉を知りたくなる。**

TOMORI は、冒険を楽しむ中で新しい言い回しや言葉の使い方に出会い、自分の表現を広げていく作品です。この言語体験は妥協しません。
ただし、作り手が意味のある体験だと考えていても、プレイヤーが面倒に感じれば続きません。言葉の豊かさは、探索・会話・景色の変化の中で実現します。入力や質問を増やして補うことはしません。

### 各クエストに必要な3点

1. その言葉を知りたくなる理由が、冒険の中にある。
2. 意味を、景色・動き・音・会話からつかめる。
3. 知った言葉を、別の場面で再び使う機会がある。

### 順番：興味が先

「気になるものに出会う → 試したくなる → 言葉が手がかりになる → 発見や変化が返る」を基本の順番にします。言葉の説明や問いより先に、先へ進みたくなる理由を見せます。

### 減らすもの・大切にするもの

| 減らす | 大切にする |
|---|---|
| 入力し直し | 立ち止まって見る |
| 同じ説明のくり返し | 違いを比べる |
| 不要な確認 | 手がかりを結びつける |
| 待つだけの時間 | 自分に合う表現を探す |
| 操作方法の迷い | 相手に伝えて、反応を受け取る |

大切な体験でも、くり返しが負担になれば、回数・長さ・タイミング・参加のしかたを見直します。手間そのものを目的にはしません。

### 実装の決まり

- 探索で「どこだろう」と考える楽しさは残す。操作がわからず困る時間は減らす。
- 長い文章の入力を毎回は求めない。発見のたびに「どう感じた？」「なぜ？」と続けて聞かない。
- 言葉を聞いて理解すること・景色と結びつけること・行動で使うことも、言語体験として設計する。
- 自分の表現を選ぶ・話す場面は、物語の上で意味があるところに絞る。そこでは新しい言い回しに出会えるようにする。
- 選ぶだけで参加できる。長く答えること・難しい語を使うことを、ごほうびの差にしない。
- 簡単な表現だけに限らない。景色・動き・会話から意味がわかるようにする。
- 会話に難しい言葉を足すだけで終わらせない。意味が、探索や行動に役立つようにする。
- わからないときは、NPC の自然な言い換えや、景色の見くらべで助ける。聞き直しやまちがいに罰はない。
- 進む条件を、特定の単語の入力や完全一致にしない。
- ことばの説明（読み方・短い意味）は、押したときだけ開く。毎回は出さない。
- 一度見た演出は、タップで先へ進められる。「あとで・冒険にもどる」と「続ける」は、どの会話でも使える。
- AI の返事は、子どもの気づきを受けとめるひとことだけ。見ていないことを言い切らない（ちがう部位・色・手ざわりを足した返事は使わない）。AI が使えなくても、固定の会話と選択肢で同じ体験ができる。
- 冒険メモの「出会ったことば」で、出会った言い回しと場面を読み返せる。覚えたかを問う小テストにはしない。

## 実装した言い回し（6つ）

「使う場面」は、オオネに冒険の気づきを伝えるときの選択肢です。選んだ言い回しは、冒険メモに「オオネに伝えた」と残ります。

| ことば | 初めて出会う場面 | 意味を伝える景色・動き | 再登場する場面 | 使う場面 |
|---|---|---|---|---|
| **ほのかに**（代表） | ポポの門のヒント「かべの絵と同じもようは、ほのかに光る花のそばにある」 | 門の足もとの青白い花：うすく、ゆっくり光る。泉のそばの「まばゆく輝く花」と見くらべられる | 道がひらいたあとの上の知らせ「ほのかに灯る石をたどって」／ひかりのつるのタネ「ほのかに青く光る」／向こう岸「島のまんなかが、ほのかに光っている」 | 門のもよう →「ほのかに光っていた花」 |
| **まばゆく** | ポポのヒント2「まばゆく輝く花ではないぞ」、泉のそばの花 | 金色の花が強く明るく、大きく脈打つ（目をほそめる明るさ） | 門をひらいたとき「かけらと門のもようが、まばゆく輝いた」／宝箱「まばゆい光があふれた」 | 門のもよう →「まばゆく輝いたもよう」／宝箱 →「まばゆくあふれた光」 |
| **まどろむ** | ポポのヒント「ねこがひなたでまどろんでいたよ」 | ねこが平たい岩の上で寝息をたて、ときどき耳がぴくっと動く（浅いねむり） | 門の向こうの寝息／「なにか大きなものが、まどろんでいる」／オオネ「ずっといっしょにまどろんでいた」 | ねこ →「ひなたでまどろむすがた」 |
| **うつむくように** | 地図のきれはし「うつむくように咲く花の絵」 | 青いベルの花が下を向いて咲く。近くの「空を向いてさく花」と向きがちがう | ミナ・花の場所／空を向く花「うつむいてはいないみたい」 | 花 →「うつむくように咲くところ」 |
| **差し込む（さしこむ）** | ねこのヒント3「光が差し込んでいる、平たい岩」 | ねこの岩に上から光の筋が落ちる | 巨木の広場に、木々の間から光の筋が3本／オオネ「木々の間から差し込む光で、目がさめた」 | ねこ →「光が差し込む岩」 |
| **きらめく** | 泉「水面がきらめいて」 | 泉の水面に小さな光がちらちらと現れては消える | 川「川の水面がきらめいて、流れが速い」（同じちらちらした光） | 泉 →「きらめく水面」 |

### 知りたくなる理由・意味がわかると進めること・もう一度使うこと

| ことば | 知りたくなる理由 | 意味の理解が、探索・行動にどう役立つか | 再登場と、そこでの使い方 |
|---|---|---|---|
| ほのかに | 門の向こうから大きな寝息が聞こえ、巨木へ行きたい。その道を見つける手がかりが「ほのかに光る花」 | まばゆい花と見くらべ、うすい光の花のそば（門）をしらべれば道がひらく。まばゆい花をしらべても罰はなく、「もっとそっとした光」と返る | 道の石・タネ・空の島。いつも「この先」を示す光として出てくる。最後に、オオネへ自分で選んで伝える |
| まばゆく | 「ほのかに」とちがうものとして、すぐに目に入る | 「ちがうほう」がはっきりわかるので、ほのかな光をさがせる | 門がひらく瞬間に、ほのかだった光がまばゆく変わる（同じ場所で意味のちがいがわかる） |
| まどろむ | ねこが起きないと、地図のきれはしが手に入らない | 浅くねむるねこは、近くでしらべると目をさます（順番が来たとき） | 門の向こうでまどろむ「大きなもの」に会いに行く |
| うつむくように | 地図に描かれた花をさがす | 下を向いて咲く花と、空を向いて咲く花を見分ける | 花の下に次の手がかり（石板）がある |
| 差し込む | ねこの居場所のヒント | 光の筋が落ちている岩をさがす | 巨木の広場で、同じ光の筋に出会う。オオネが目ざめた理由として出てくる |
| きらめく | 「水の音が聞こえるところ」の手がかり | 水面のちらちらした光で泉や川を見つける | 川は流れが速くて渡れない。橋が必要になる |

**進むのに必要な鍵**は「ほのかに」の1組だけです。ほかの5つは、景色の見え方を変えたり、手がかりを読みやすくしたりする言い回しです。どの言い回しも、特定の単語を書かせて進む条件にはしていません。

## 代表クエスト「ほのかな光をさがせ」の流れ

1. **気になるものに出会う**：ほらあなのかべの絵を見つけたあと、巨木がかすかに光る。草原の南西のはしでは、門の向こうから「すう……ふう……」と大きな寝息が聞こえる。門が画面の外でも、聞こえる側の画面のはしに出る。
2. **言葉が手がかりになる**：ポポ（またはミナ）に話すと「かべの絵と同じもようは、ほのかに光る花のそばにある」。聞き直すと「まばゆく輝く花ではないぞ。そっと光る、ほのかな光の花じゃ」と、くらべ方を教えてくれる。「ほのかに」の意味は、押したときだけ開く。
3. **見くらべる**：泉のそばに、まばゆく輝く金色の花。しらべると「まばゆく輝く花だ！」に続けて「さがしているのは、ほのかに光る花。もっとそっとした光みたい」。何も進まず、罰もない。
4. **発見する**：門の足もとに、うすく光る青白い花。門をしらべると、かけらと門のもようが**まばゆく**輝き、道がひらく。
5. **変化が返る**：道の石が、手前から巨木へ向かって**ほのかに**灯る。光の粒が浮かび、歩くと音が少しずつ高くなる。上の知らせは「ほのかに灯る石をたどって、巨木の根もとへ」。
6. **別の場面で使う**：オオネに「何が気になった？」と聞かれて「光った門のもよう」を選ぶと、手がかりに「ほのかに光っていた花」と「まばゆく輝いたもよう」が並ぶ。選んだ言い回しの意味は、その下に出る。

### 必須の会話・任意の会話・入力の回数

| 場面 | 必須 | 任意 |
|---|---|---|
| ポポ（門のヒント） | ヒント1（ほのかに光る花のそば） | ヒント2・3（くらべ方・場所）、ことばの説明 |
| まばゆく輝く花 | なし | しらべると、くらべるひとこと |
| 門 | しらべる（1回） | なし |
| オオネ | 目ざめのことば（2区切り）、問い2つ（選ぶだけで進める） | 自分のことばで書く・声で話す |
| 途切れた道 | 植える（1回） | なし |

- **文字の入力が必要な回数：0回。** オオネへの答えは、選ぶだけで最後まで進めます。書いたり声で話したりもできます。
- AI の通信は、子どもが自分のことばを書いたときだけ、1回です。

## 操作の手間の見直し

### 実装した改善

| 見直したところ | 前 | 今回 |
|---|---|---|
| ことばの説明 | 説明のあることばが出るたびに、いつも表示 | 「〜って？」を押したときだけ開く（読む量が減る） |
| 演出 | 道がひらく・目をさます・橋が育つを、毎回最後まで待つ | 0.8秒をすぎたら、タップで先へ（「タップで先へ」と出る）。ごほうびは演出の前に決めて保存してあるので、飛ばしても同じ |
| オオネとの話のやり直し | 「また来てくれたんだね」→「うん、話す」→問い | もどってきたひとことと問いを、同じ画面に（1タップ減） |
| 門をひらいたあとの道 | 門をタップすると、門の説明がまた開く | ひらいた門・橋ができた場所はタップで選ばない。奥の道をタップすると、そのまま歩く |
| 小さい画面の会話 | 上の知らせが2行になり、相手がパネルの下にかくれる | 会話のあいだだけ上の知らせを隠す |
| 小さい画面のボタン | 説明を開いてパネルがのびると、下にはりつくボタンの下に「もっとくわしく聞く」がかくれる | ボタンの下にゆとりを取って、かくれないように |

### 大きな変更の提案（まだ実装していない。判断待ち）

1. **写真から始まるクエストの入力を、選ぶ方式と並べる**
   - 理由：最初のクエストだけ、写真のあとに自由入力が必須です。「長い文章の入力を毎回求めない」に合わない。
   - 画面案：写真を選んだあと、写真の上に3つのことばのカード（例：「まるい」「ほのかに光る」「うつむくように」）と「自分のことばで書く」を並べる。カードを選ぶだけで、ことばのタネが生まれる。
   - 判断が必要な点：最初のクエストは提出版の中心の体験なので、HQ と制作者の判断が必要です。
2. **冒険メモの「出会ったことば」から、その場所へ案内する**
   - 理由：ことばを読み返したあと「もう一度見たい」と思ったときに、迷わずにすむ。
   - 画面案：ことばの行に「その場所へ」ボタン。押すと、ヒントの光（6秒）がその場所に出る。歩く楽しさを残すため、自動では歩かない。
3. **一度聞いたヒントの短縮**
   - 理由：同じ人に話しかけるたびに、同じヒントの全文が出る。
   - 画面案：2回目からは、ヒントの1行目だけを出し、「くわしく」で全文を開く。

## 子どもが遊ぶときの観察（自動テストとは別に）

面白さや学習効果は、自動テストの合格だけでは確かめられません。子どもが遊ぶ様子を、次の手順で見てください。

**準備（5分）**：開発版をスマホで開き、「デモを最初から」を押す。宝さがしを終えた記録から見るときは、制作者が先にほらあなまで進めておく。

**見ている人は、口を出さない。** 困っていそうでも、1分は待つ。

| 見るところ | 見るしるし | 記録 |
|---|---|---|
| 自分から試すか | 「まばゆく輝く花」と門の足もとの花を、自分からしらべに行くか。ポポのヒントを聞き直すか | した・しない・何分後 |
| 会話を読み飛ばすか | 会話のパネルをすぐ閉じるか。「〜って？」を押すか | すぐ閉じた回数・押した回数 |
| 同じ場所で困り続けるか | 同じ場所を1分以上うろうろするか。どこで止まったか | 場所・時間 |
| 言葉を使うか | オオネへの答えで、「ほのかに」「まばゆく」をふくむ手がかりを選ぶか。自分で書いたか | 選んだもの・書いたか |
| 先へ進みたい気持ち | 寝息・巨木の光を見て、何か言ったか（「なにかいる！」など） | 子どものことば（そのまま） |

**遊んだあとに聞く（2問だけ）**

1. 「ほのかに光るって、どんな光だった？」（ことばで答えても、指さしでもよい）
2. 「もっと行ってみたいところはあった？」

結果は、場所・時間・子どものことばをそのまま残し、次の調整に使います。点数はつけません。
