# TOMORI デモのルビ（読みがな）の扱い

## いまの扱い（Step 11K-B・2026-10-05）

ゲームの画面には、ルビを表示しない。

## 理由

これまでは、言葉カードの見出しのうち、漢字をふくむ語にだけルビを付けていた。
ひらがなだけの語にはルビが付かないため、同じ画面に「ルビのあるカード」と「ないカード」が並んでいた。
ルビのあるカードだけ見出しの行が高くなり、カードの高さもそろわなかった。
また、同じくらいの難しさの言葉でも、表記によって付いたり付かなかったりして、子どもから見て基準が分からなかった。

この不統一をなくすため、ルビをいったんすべて外した。
「ルビは要らない」と判断したわけではない。部分的で基準のないルビを解消するための、暫定の対応である。

## 変えたこと・変えていないこと

- 言葉カードの見出しは、`textContent` で語をそのまま表示する（`<ruby>` `<rt>` を作らない）
- ルビ専用の CSS（`ruby` `rt`）を削除した
- 語・漢字・意味・並び順は変えていない
- 読み（`reading`）はデータに残している。AI の応答の形・検査（`reading` は必須）・Worker の通信は変えていない
- 画面に出す文字は、外から来た文字列を HTML として入れない（今までどおり）

## 以前ルビが付いていた語

端末内の候補（AI を使わないとき・使えないとき）のうち、表記と読みが違う20語。

| 種類 | 語 |
|---|---|
| 気もち | 目を奪われる／息をのむ／心が動く／心がはずむ／苦手／不安／穏やか／落ち着く／心細い |
| 「やばい」だけのとき | 気になった／心が動いた |
| 見るところ | 表情／色合い／輪郭／色／形／動き |
| 起きたこと | 様子／変化／流れ |

AI が返す語でも、漢字をふくむ語には同じ仕組みでルビが付いていた。
確認用のスタブでは、次の語が当てはまる。

- 心がはずんだ
- 顔つき
- 寝姿
- 寝ていた場所
- まわりの様子

## これから検討すること（別の Step）

- 学年に合わせて、ルビを付けるかどうかを決める
- 画面で「ルビあり／なし」を切り替えられるようにする
- 付ける場合は、すべての漢字に同じ基準で付ける（一部の語だけに付けない）

読み（`reading`）をデータに残しているのは、この切り替えをあとから作れるようにするためである。
