# 市場町（TOWN-01）の計画と現状

本戦に向けて、草原の東に、明るい中世ヨーロッパ風の小さな市場町を足します。
いちばん大事な考え方は「もっと冒険したいから、言葉を知りたくなる」です。

状態の書き方：**実装済み**（コードにある）／**検証済み**（テストやヘッドレス Edge で確かめた）／**実機未確認**（iPhone ではまだ）／**予定**。

## 配置

- 入口：草原の東のはし（34, -6.2）。ゆるく曲がる大通り（幅5.2m）を進むと、木のアーチと花かざりの街の門。
- 大通りの先は噴水の広場（中心 61.6, -6.4、半径7.8m）で、噴水のまわりに屋台が4軒ならぶ。
- 広場の北東から分かれる「庭の路地」（幅4.2m）の先には、庭のある家が3軒ならぶ小さな広場があります。
- 南東の「見晴らしの路地」（幅4m）の先は、ベンチと、東へひらける景色。
- 曲がり角はどれも45°以下です。6.6m/秒のまま曲がれる道幅と曲率にしました（速さは落としていません）。
- 家・噴水・屋台・花壇には入れません。タップした先へは、見通せる点をたどって歩きます（家の裏へ回りこみません）。
- 道・広場・家の座標は `demo-world.html` の `TOWN-LAYOUT` にあります。家は道から0.25m以上はなれていることを `test-town.mjs` が確かめます。

上から見た図は `docs/TOWN_LAYOUT.png` です。

### 見通しとカメラ

- 街へ近づくと、カメラが少しずつ回って、通りの先を見ます。街の中では、タップで歩いている向きのうしろへ、ゆっくり回りこみます。止まっているときと、キーで歩くときは回しません。
- 家・屋台が、カメラとヒロリ（会話のときは話す相手も）のあいだに入ったら、点を抜いて透かします。家は大きいので、木よりうすく透かします（0.14）。
- カメラが家の中に入りそうなときは、ヒロリの側の、家の手前まで寄せます。

## お手伝い：花屋のお届けもの

ひとつずつ手がかりをつかめるように、2段階にしました。

1. 花屋のリリに話しかけ、「手伝う」を押す。
2. 「うつむくように咲く花」をえらぶ。台の上の鉢は3つで、色は同じです。花の向き（上・下・横）だけがちがいます。
   - まちがえると、ちがいがわかる短い返事だけが出ます（罰はありません）。
3. 届け先は「日差しが差し込む庭のおうち」。庭のある3軒は、光のようすだけがちがいます。
   - 屋根のすきまから光の筋がおりる庭（正解）
   - 大きな布のひさしのかげになった庭
   - ランタンの明かりで照らされた庭
4. 正しい庭に届けると、ソラばあちゃんから10コイン。お礼は1回だけです。

- ヒント：「ヒントを見る」を押したときだけ、1つずつくわしくなる（3段階）。
- 「〜って？」を押すと、ことばの短い説明が開きます。
- 冒険メモには、お願い・届け先・聞いたヒントが残る。
- 「あとで」で閉じても、続きから再開できます。
- 正解・ごほうび・進み方を決めるのは、固定のデータだけ。AI の返事では変わりません。

## コインとお店

コインはゲームの中だけで使うもので、課金や決済の仕組みはありません。

| 品物 | 値段 | 特徴（ことば） | 育った姿 |
|---|---|---|---|
| ひだまりのタネ | 5コイン | ひだまりが好き。空を向いて、大きな黄色い花がひらく | せの高いくきの先に、空を向いた黄色い花 |
| つりがねのタネ | 8コイン | 少しの日かげでも育つ。うつむくように、白い鈴の花がたくさん咲く | しなるくきに、うつむいた白い鈴の花 |

- お礼の10コインでは、どちらか1つしか買えません。買う・買わない・貯めるに、正解・不正解はつけません。
- 買う前に、値段・特徴・育った姿・買ったあとの残高を見られます。閉じるボタンは「今は買わない」です。
- 買ったタネは、広場の花壇に植えられます。つぼみがほころび、説明どおりの形の花が育ちます。
- 植えたタネは、もう一度は使えません。同じタネは1つまでです。
- コインを使い切っても、ほかの冒険は進められます。

## 保存

- 街の記録は、宝さがしとは別のキーに保存します。本番は `tomori-town-v1`、開発版は `tomori-town-v1-preview` です。
- 届ける・買う・植えるは、記録を変えて保存してから、音や演出を見せます。読み込み直しても、コイン・タネを失いません。
- 残高は「お礼 − 買ったタネの値段」から計算して読みもどす。記録に書かれた数字は使わないので、増えも減りもせず、マイナスにもならない。
- 写真と自由入力のことばは、今までどおりページを開いているあいだだけです。新しい外部保存や送信はありません。
- 「デモを最初から」で、街の記録も消えます（確認の文にも書きました）。
