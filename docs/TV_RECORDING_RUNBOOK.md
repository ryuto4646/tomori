## 2. 起動と終了

### 起動のしかた（どちらか1つ）

**A. ダブルクリックで起動する（おすすめ）**

1. エクスプローラーで `C:\Users\DELL\Documents\tomori-next` を開く。
2. `start-tv-demo.cmd` をダブルクリック。
3. 黒い画面に「AI スイッチ：オン」と出ていれば準備完了です。
4. 2秒ほどで、いつものブラウザに次のページが開きます。
   `http://localhost:3458/demo-world.html`
5. 黒い画面は、収録が終わるまで閉じないでください。閉じるとページが動かなくなります。

**B. コマンドで起動する**

コマンドプロンプトを開き、次の2行を順に入力します。

```
cd /d C:\Users\DELL\Documents\tomori-next
python -m http.server 3458 --bind 127.0.0.1 --directory .
```

そのあと、ブラウザで `http://localhost:3458/demo-world.html` を開きます。

### 守ること

- **管理者として実行しない**でください。ふつうのダブルクリックで動きます。
- `--bind 127.0.0.1` を消さないでください。これがあるので、同じ Wi-Fi のほかの端末からはこのページが見えません。
- **LAN の IP アドレス**（`http://192.168.…` など）では開かないでください。語彙の Worker が受け付けないので、AI の言葉が出ません。
- 新しいソフトやパッケージは入れません。Python に最初から入っている機能だけを使います。

### 終了のしかた

黒い画面をクリックしてから、`Ctrl` キーを押しながら `C` を押します。
「バッチ ジョブを終了しますか (Y/N)?」と出たら、`Y` を押して `Enter` を押します。

### 「ポート 3458 は、ほかのプログラムがもう使っています」と出たとき

すでに同じサーバーが動いていることがほとんどです。

1. まず、ほかに黒い画面が開いていないか探してください。あれば、それをそのまま使うか、上の方法で終了します。
2. 見つからないときは、コマンドプロンプトで次を入力。

   ```
   netstat -ano -p tcp | findstr ":3458"
   ```

   `LISTENING` の行のいちばん右の数字が、使っているプログラムの番号です。
   タスク マネージャーの「詳細」タブで、その番号（PID）のプログラムを確かめてから終了してください。

## 3. 収録前のチェック

上から順に確かめます。1つでも合わなければ、「7. 困ったとき」を見てください。

- [ ] 3D の世界とヒロリが表示されている
- [ ] 黄色い光るポイントに近づくと、ミッションが「気になったものを、ひとつ見つけよう」と出る
- [ ] 起動の黒い画面に「AI スイッチ：オン」と出ている
- [ ] インターネットにつながっている
- [ ] 語彙の Worker につながる
  - ブラウザの新しいタブで `https://tomori-vocabulary.tomori-ryuto.workers.dev/vocabulary` を開きます。
  - `{"error":"Method not allowed","code":"METHOD_NOT_ALLOWED"}` と出れば、つながっています。
  - この確認では AI は動きません。回数制限にも数えられません。
- [ ] ページで `F12` を押し、「Console（コンソール）」タブに赤いエラーが0件
- [ ] 送るのは、話した言葉・ミッションの文・学年・言語の4つだけ。写真・声・名前・履歴は送らない（写真はこの PC の外へ出ません）
- [ ] Preview URL（`…workers.dev` 以外の、版ごとの URL）は使わない

## 4. 収録の操作の順番

1. 画面をタップ（パソコンなら W A S D か矢印キー）して、ヒロリを歩かせる
2. 黄色い光るポイントに着くと、ミッションが出る →「さっそく探す！」
3. 写真を選ぶ（「いま見つける」か「思い出から探す」）→「この写真を使う →」
4. 「何が気になった？」に、自由な言葉を入力するか、「声で話す」で話す →「ことばをひろげる →」
5. 3枚の言葉のカードから1枚を選ぶ
6. 花が咲く
7. 深掘りの問いが出る（答えても、「今は進む」でも大丈夫）
8. 右上の「デモを最初から」でリセットする

## 5. 出演者への案内

- 次のように案内してください。
  **「写真を見て、気になったことをそのまま教えてください」**
- 答えは、ものの名前・起きたこと・気持ち・「わからない」の、どれでも大丈夫です。
- 次のことはしないでください。
  - 「やばい」など、特定の言葉を言うように頼む
  - 気持ちを答えるように求める
  - 写真に写すものを指定する

---

## 6. 回数の制限

- 同じタブから AI へ送れるのは、**60秒に6回まで**です。
- 続けて撮るときは、1回ごとに少し間をあけてください。
- 上限を超えても画面は止まりません。端末の中の言葉のカードに切り替わり、そのまま最後まで進めます。
- 撮り直すときも、何度も続けて送らないでください。60秒以上あけてから送り直します。

## 7. 困ったとき

| こんなとき | すること |
|---|---|
| AI の言葉が返ってこない | そのまま進めて大丈夫です。「今日は、トモリが見つけた言葉から選んでみよう。」と出て、端末の中の言葉のカードで続けられます |
| AI の言葉が出ない（403） | アドレスが `localhost:3458` になっているか確かめます。LAN の IP アドレスで開いていたら、`http://localhost:3458/demo-world.html` で開き直します |
| AI の言葉が出ない（429） | 送りすぎです。60秒以上待ってから続けます。そのあいだも端末の中の言葉で進められます |
| 画面が出ない・真っ白 | 起動の黒い画面が開いたままか確かめます。インターネットにつながっているかも確かめます（3D の部品をインターネットから読み込むため） |
| 声で話せない | 「書いてもOK」の欄に、文字で入力します |
| AI をすぐ止めたい | 下の「緊急停止」の手順で止めます |

### 緊急停止（AI を使わないようにする）

1. `demo-world.html` をメモ帳で開きます。
2. `const VOCABULARY_AI_ENABLED = true;` を探し、`true` を `false` に書きかえて保存します。ほかの場所は変えません。
3. 起動し直すと、黒い画面に「AI スイッチ：オフ」と出ます。ブラウザのページも再読み込みします。
4. 言葉を入力すると、端末の中の言葉のカードが出ることを確かめます（外への送信は0回になります）。

補足：自動テストの一部は「スイッチがオン」であることを確かめています。そのため、緊急停止のあとにテストを実行すると、次の3つが失敗します。これは正常です。

- `test-hirori-placeholder.mjs` の 17
- `test-world-effects.mjs` の 6
- `test-vocabulary-integration.mjs`（ファイルの最初でスイッチを確かめるため、ファイル全体が止まる）

もとに戻すときは、`false` を `true` に戻して保存し、ページを再読み込みします。

### してはいけないこと

- Secret や API キーを、画面・コマンド・チャットに貼らない
- Cloudflare や Anthropic の設定を、収録中に変えない

## 8. 収録のあと

1. 黒い画面で `Ctrl` と `C` を押して、サーバーを止める（「2. 起動と終了」を参照）。
2. ブラウザのタブを閉じる。匿名のセッション ID（sessionStorage）は、タブを閉じた時点で消えます。
3. 困ったことがあった場合は、次の3つだけを記録します。
   - HTTP の状態（例：403、429）
   - 時刻
   - 画面の状態（どの画面で、何が出ていたか）

   **出演者が話した言葉や写真は、記録しないでください。**
